# PAIOS-Integrationen

PAIOS bleibt modellunabhängig. Nutze den Validator vor jedem Import.

- Claude: MCP mit mcp/claude_desktop_config.snippet.json.
- Andere Modelle: Vault als Markdown-Kontext oder über den read-only Adapter lesen.
- Lokale Modelle: gleiches Dateiformat, keine Anbieterabhängigkeit.

## Regel

MCP ist eine Schnittstelle, nicht die Datenbasis. Keine Schreibrechte ohne explizite Bestätigung und Audit.
