# PAIOS - System Principles

1. Wissen gehoert dem Nutzer.
2. Modelle sind austauschbar.
3. Der Workflow bleibt stabil.
4. Offene Standards bevorzugen.
5. Modularitaet vor Komplexitaet.
6. Mensch definiert Ziele; KI unterstuetzt.
7. Dokumentation ist die zentrale Wissensquelle.
